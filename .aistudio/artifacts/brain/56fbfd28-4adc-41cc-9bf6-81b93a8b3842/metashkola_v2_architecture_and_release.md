## 1. Назначение и концепция проекта

**MetaШкола 2.0** — единая модульная образовательная платформа, объединяющая веб-приложение (PWA) и нативное мобильное приложение для Android в масштабируемую систему взаимодействия семьи, школы и учеников.

### Ключевые архитектурные принципы:
- **Offline First:** Приложение на 100% автономно. Полный доступ к расписанию, звонкам, заданиям, оценкам и локальному ИИ без подключения к интернету.
- **Mobile First:** Интерфейс спроектирован для сенсорного управления с нижним навигационным доком, поддержкой безопасных зон (safe area insets) и адаптацией под экраны от 320px до десктопов 4K.
- **Multi-tenant / Multi-space:** В рамках одного аккаунта пользователь может состоять в нескольких пространствах (Семья, Школа, Личное).
- **Строгий RBAC:** 9 ролей с разграничением прав на уровне объектов и пространств (Создатель, Сисадмин, Администратор школы, Администратор семьи, Родитель, Учитель, Классный руководитель, Ученик, Гость).
- **Защита несовершеннолетних:** Флаг `aiRestrictedForMinors` блокирует доступ к внешним облачным сервисам ИИ для учеников без явного согласия администратора.
- **Universal AI Gateway:** Поддержка провайдеров Google Gemini, OpenAI, xAI Grok, Anthropic Claude, DeepSeek, Mistral, OpenRouter, локальных серверов (Ollama) и встроенного оффлайн-репетитора.

## 3. Спецификация Android-приложения

| Параметр | Значение | Обоснование |
|---|---|---|
| **Application ID** | `org.metaschool.app` | Уникальный пакет в экосистеме Android |
| **Минимальная версия OS** | Android 5.0 (API Level 21) | Полный охват широкого парка устройств |
| **Целевая версия OS** | Android 14+ (API Level 34) | Соответствие современным требованиям Google Play и безопасности |
| **Целевое устройство** | OPPO A74 (Qualcomm Snapdragon 662) | Оптимизация под ColorOS и фоновое энергосбережение |
| **Архитектуры процессоров** | `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64` | Нативная поддержка 64- и 32-битных чипов |
| **Технология ядра** | Высокопроизводительный Android WebView Wrapper + Kotlin Core | Единственное решение, сочетающее API 21 и 100% переиспользование UI |
| **Фоновые уведомления** | `NotificationManagerCompat` + `AlarmManager.setExactAndAllowWhileIdle()` | Гарантированная подача сигналов уроков и звонков при выключенном экране |
| **Нативный мост** | `MetaSchoolNativeBridge` | Вызов системных вибраций, уведомлений и проверка сети из JS |
| **Автономные ассеты** | `file:///android_asset/www/` | Локальная загрузка бандла без обращения к серверу |

## 4. Расписание звонков и логика времени

Стандартные настройки расписания (редактируемые в разделе «Звонки»):
- **Начало 1-го урока:** 08:00
- **Длительность урока:** 45 минут
- **Обычная перемена:** 10 минут
- **Большая перемена:** 20 минут (после 3-го урока)
- **Количество уроков в день:** 6
- **Напоминания:** за 5 и 15 минут до звонка
- **Звуковой сигнал:** Полифонический Web Audio синтезатор (C5-E5-G5-C6) при начале урока и окончании перемены.

## 6. GitHub CI/CD Workflows

1. **`web-ci.yml`:** Проверка линтинга (`npm run lint`), юнит-тесты логики звонков и прав (`logic.test.ts`), production-сборка `vite build`.
2. **`android-ci.yml`:** Автоматическая сборка Android Debug APK через Gradle и выгрузка APK-артефакта в CI.
3. **`release.yml`:** Запуск по Git-тегу `v*`, расшифровка защищенного keystore из GitHub Secrets, компиляция `assembleRelease`, подсчет SHA-256 и публикация в GitHub Releases.
