## 1. КОНЦЕПЦИЯ ПРОДУКТА

### 1.1. Общая идея
MetaШкола — персональная цифровая экосистема, объединяющая образование, личную организацию, коммуникацию, управление временем, интеллектуальные инструменты и персональные пространства пользователя.

Первоначальная образовательная направленность сохраняется, но продукт перестаёт ограничиваться школьными сценариями. MetaШкола создана для:
- школьника и студента;
- родителя и семьи;
- учителя и наставника;
- самостоятельного пользователя;
- организатора группы или сообщества.

**Ключевой принцип:** *Сначала целостность данных. Затем надёжность обмена. Затем новые возможности.*

### 1.2. Продуктовые принципы
1. **Offline-first:** основные пользовательские сценарии обязаны работать без подключения к сети.
2. **Mobile-first:** смартфон — главный форм-фактор, поддерживаемый нативным Android контейнером.
3. **Cross-platform:** единая продуктовая логика на всех платформах (Web, PWA, Android).
4. **Modular:** модули развиваются независимо, взаимодействуя через общее ядро.
5. **Personalizable:** пользователь настраивает интерфейс, палитры, плотность и рабочее пространство.
6. **Native integration:** использование реальных Android API (AlarmManager, WebChromeClient camera permissions, NotificationManager).
7. **Transparent:** честные статусы синхронизации (`local_synced`, `pending`), отсутствие фиктивных облачных серверов.
8. **Secure by design:** локальное шифрование AES-GCM (PBKDF2), RBAC разграничение доступа, санитизация секретов.
9. **Data ownership:** экспорт данных в открытом формате MetaShare (.mspack с SHA-256).
10. **Graceful degradation:** при отсутствии прав или сети приложение продолжает функционировать и честно объясняет ограничения.

### 2.1. Основные модули
- **MetaEducation:** Расписание уроков, звонки, предметы, домашние задания, оценки, успеваемость, исключения.
- **MetaPersonal 1.1:** Личные заметки с тегами и поиском, задачи с приоритетами и дедлайнами, трекер привычек со стриками, списки покупок (`ShoppingList`).
- **MetaCommunity:** Группы классов, тематические клубы, семейные советы, публикации с реакциями и комментариями, система модерации.
- **MetaTools:** Точный таймер на абсолютных временных метках (устойчивый к фону), секундомер, будильники с нативной интеграцией `MetaSchoolNative.scheduleAlarm`.
- **MetaAI:** Локальные ролевые ассистенты (Репетитор, Математик, Языковой ассистент, Планировщик) с безопасным контекстом.
- **MetaSystem:** Единый центр управления: профили, безопасность, оформление, уведомления, хранилище.
- **MetaDeveloper:** Инструментальная панель L0–L5 readiness, аудит-лог, экспорт без секретов, метрики хранилища.
- **MetaShare:** Криптографический обмен данными с контрольными суммами SHA-256 и валидацией ссылочной целостности.

## 4. ПЛАН ДАЛЬНЕЙШЕГО РАЗВИТИЯ (ЭТАПЫ 2.2.1 → 3.0)

1. **Серверный транспорт MetaCommunity:** Реализация REST/WebSocket сервера с E2EE для сквозного шифрования личных диалогов.
2. **P2P Синхронизация MetaShare:** Обмен расписаниями по локальной сети через WebRTC / Local Wi-Fi без внешнего сервера.
3. **Нативные виджеты Android:** Виджет расписания уроков и таймера на рабочем столе Android через RemoteViews.
4. **Многопрофильная синхронизация:** Синхронизация семейного пространства между устройствами родителей и детей.
