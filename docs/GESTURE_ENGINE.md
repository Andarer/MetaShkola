# GESTURE ENGINE — СИСТЕМА ЖЕСТОВ METASHKOLA 2.0.2

Модуль управления жестами и касаниями обеспечивает тактильный и нативный мобильный опыт при взаимодействии со смартфоном (OPPO A74, Xiaomi, Samsung, Pixel) и планшетом.

## 1. СТАНДАРТНЫЕ ДЕЙСТВИЯ

| Жест | Действие | Описание |
| :--- | :--- | :--- |
| **Tap (Касание)** | Открытие | Открывает детали урока, задание или карточку профиля |
| **Long Press (Долгое нажатие)** | Контекстное меню | Открывает Bottom Sheet с быстрыми действиями (редактировать, удалить, поделиться) с виброоткликом Haptic |
| **Swipe Left / Right** | Навигация по дням | Переключение дней недели в расписании звонков и уроков |
| **Swipe Down (Pull-to-refresh)** | Синхронизация | Обновление расписания и сброс кеша очереди действий |
| **Drag & Drop** | Перемещение | Перетаскивание уроков для быстрой перестановки в расписании |

## 2. HAPTIC FEEDBACK (ВИБРООТКЛИК)
Интеграция с Android Native Bridge через системный `VibrationEffect`:
- **Выбор и касание:** 15–20 мс (едва уловимый щелчок).
- **Контекстное действие:** 40 мс.
- **Звонок на урок / перемена:** 250 мс пульсация.
- **Ошибка / предупреждение:** Двойной импульс (50 мс – пауза – 50 мс).

Поддерживается отключение в «Настройки → Уведомления и звуки».
