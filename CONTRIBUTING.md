# Руководство по участию в разработке (CONTRIBUTING.md)

**Проект:** MetaШкола 2.0  
**Автор и инициатор:** Andárer

---

## 1. Процесс разработки

1. Форкните репозиторий и создайте ветку от `develop`:
   `git checkout -b feature/название-функции` или `git checkout -b fix/описание-ошибки`.
2. Вносите изменения с соблюдением стандартов TypeScript и Tailwind CSS v4.
3. Обязательно проверяйте код перед коммитом:
   ```bash
   npm run lint
   node --test src/lib/ms/logic.test.ts
   npm run build
   ```
4. Отправьте Pull Request в ветку `develop`.

---

## 2. Стандарты кода

- **Strict TypeScript:** Не используйте тип `any` без крайней необходимости.
- **Интернационализация:** Любой текст в интерфейсе должен добавляться через словарь `src/lib/ms/i18n.ts` на трех языках (`ru`, `uk`, `en`).
- **Offline First:** Любой новый экран или компонент должен сохранять работоспособность при отключении сети.
- **Безопасность:** Не передавайте личные данные несовершеннолетних во внешние сервисы.
